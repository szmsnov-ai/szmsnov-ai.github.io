OC — частное приложение

Приложение для личного использования владельцем. Не предназначено для других пользователей.

Политика конфиденциальности

Приложение получает доступ к данным Google-аккаунта владельца (Gmail, Календарь, Диск) только для его личной автоматизации. Данные не продаются и не передаются третьим лицам, кроме сервисов, которые владелец сам использует для обработки.
